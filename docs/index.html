Características Principales

Todo lo que necesitas para registrar y visualizar tus gastos.

Voz Instantánea

Doble toque en el botón de volumen. Di el gasto, se guarda solo. Sin abrir la app.

100% Offline

Base de datos local SQLite con Room. Sin internet, sin servidores, sin suscripciones.

Parsing Inteligente

Entiende "Comida, veinticinco, almuerzo en la universidad" en español natural.

Estadísticas Ricas

Gráficos circulares por categoría, barras semanales y barras de presupuesto rojo/verde.

Material Design 3

Interfaz moderna y familiar. Modo oscuro, animaciones nativas y accesibilidad completa.

Acceso Rápido

Tile en ajustes rápidos del panel de notificaciones. Registra un gasto sin ni abrir la app.

Cómo Usarlo

Tres pasos. Menos de cinco segundos.

1

Activa

Doble toque rápido en el botón de volumen, o abre la app y presiona "Por Voz".

2

Dicta

Habla en formato categoría, monto, comentario.
Ejemplo: "Comida, veinticinco, almuerzo en la universidad"

3

Listo

El gasto se guarda automáticamente con categoría, monto y comentario. Sin tocar nada más.

¿Prefieres hacerlo a mano? También puedes registrar gastos manualmente desde la pestaña Gastos, completando categoría, monto y comentario en el formulario.

Comenzar

Clona el repositorio y ejecuta en Android Studio.

bash 
git clone https://github.com/josetra44/kolki.1.0.git
cd kolki.1.0
1 Abre el proyecto en Android Studio Arctic Fox o superior.
2 Sincroniza el proyecto con Gradle (Sync Now).
3 Conecta un dispositivo Android API 26+ o abre el emulador.
4 Presiona Run ▶ y otorga permiso de micrófono.

Requisitos mínimos

  • Android Studio Arctic Fox o superior
  • SDK mínimo: API 26 (Android 8.0)
  • SDK objetivo: API 36 (Android 15)
  • Kotlin 2.0.21
  • Java 17
